Meha-LuPi Emulator - это реализация OpenComputers эмулятора на Python с использованием ИИ технологий.
__________

Для запуска необходимо:
* Python 3.9+ (на самых новых версиях не тестировалось)
* зависимости (pip install -r requirements.txt)
* Windows XP и выше (если вы используете пропатченнную версию для данной ОСи)

Предоставлен initgui.py для более удобного запуска эмулятора в графическом виде, но доступна и старая консольная версия init.py.
__________

Данный код был основан на исходниках других проектов, без которых существование этого ИИ-слопа не случилось бы:

* LuPI2: https://github.com/Starchasers/LuPI2
* OCEmu: https://github.com/BlueAmulet/OCEmu
